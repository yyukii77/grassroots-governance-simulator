# 设身处地 · 基层治理模拟器

一款单文件 HTML 社会运行模拟游戏，从 1980 年改革开放起步，扮演乡镇党委书记，完整模拟中国基层社会运转。

## 在线游玩

👉 **[点击开始游戏](https://yyukii77.github.io/grassroots-governance-simulator/)**

## 核心系统

- **社会运行引擎**：2000+ 市民 Agent、家庭系统、80+ 企业 Agent（22 行业）、就业市场、教育医疗社保
- **政务管理五大模块**：人事任免、工程招投标、工商审批、政策申报、权力运作
- **历史事件系统**：1980-2024+ 30+ 真实历史事件（经济特区、南巡、分税制、入世、奥运、新冠等）
- **污染热力图**：真实建筑污染扩散 + 绿地净化
- **DeepSeek AI 自主治理**：AI 自主操控角色决策、建造、制定政策，可自动玩 20 局并生成分析报告

## 本地运行

直接用浏览器打开 `基层治理.html` 即可，无需任何依赖。

## AI 功能使用

1. 游戏内左侧 → "社会"标签页 → 底部 "AI 设置"
2. 输入你的 DeepSeek API Key
3. 点 "AI 自主治理控制台" → 启动 AI

## 技术栈

纯原生 HTML/CSS/JavaScript，单文件 280KB，无外部依赖。
